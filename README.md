# Notulen AI (APK)

1. Buat repository baru di GitHub, unggah SEMUA isi folder ini (termasuk folder `.github`, `www`, `assets`).
2. Buka tab **Actions** → tunggu workflow **Build APK** selesai (±5-8 menit). Bisa juga dijalankan manual lewat *Run workflow*.
3. Klik run yang berhasil → bagian **Artifacts** → unduh `notulen-ai-apk` → ekstrak → `app-debug.apk`.
4. Pindahkan ke HP, izinkan *Install dari sumber tidak dikenal*, lalu pasang.
5. Buka aplikasi → isi **API key Anthropic** di Pengaturan AI (console.anthropic.com).
